## Coverage rule

“Useful feature area” does not mean adopted. Each remaining row is either already implemented locally, deliberately adapted independently, or deferred with a concrete compatibility/licensing reason. A future feature intake should change this matrix and the source-specific review record in the same commit as any implementation. In particular, do not treat the large feature sets of HLstatsZ as a checklist for indiscriminate porting: several require external databases, new identities/permissions, server-side writes, or incompatible protocol assumptions.
